# CloudMail V1.1.3

V1.1.3 is a security and release hardening version for official public use. It stays compatible with existing Cloudflare Temp Email Workers, mailboxes and admin operations.

## Important upgrade notice

GitHub APKs for V1.1.2 and earlier use the Android Debug certificate; from V1.1.3 builds use the private EAS production certificate. Android does not allow apps signed with different certificates to install over each other, so older versions cannot upgrade directly to V1.1.3.

Existing users should migrate in this order:

1. Before uninstalling, note each Worker's URL, frontend URL, admin password and site password.
2. On the Mailboxes page, open each account you want to keep, then copy and safely store its mailbox credential; or confirm you can sign in again with the email address and password.
3. Once the credentials are saved somewhere safe, uninstall V1.1.2 or earlier.
4. Install V1.1.3, configure the Workers again, and restore mailbox accounts with "Credential import" or "Password sign-in".

Do not uninstall the old version before saving your credentials. Uninstalling on Android deletes the app's local configuration.

## What's new

- Worker admin passwords, site passwords, mailbox JWTs and mailbox passwords move to the system SecureStore on Android/iOS.
- Migration completes the secure write first, then deletes the plaintext in AsyncStorage; if secure storage fails, the old data is kept to avoid silent loss.
- Secure reads for multiple Workers/mailboxes now run in parallel to shorten startup; unused keys are cleaned up when configurations are deleted.
- Worker connection tests accurately distinguish site password, admin password, API incompatibility, timeout, rate limiting and Worker 5xx errors.
- Removed unused notification, audio, video and image native modules.
- Blocked unrelated Android permissions such as notifications, recording, boot start, wake lock, external storage and overlays, and disabled app data backup.
- Added privacy policy and terms of use links in Settings.
- CI adds gates for types, tests, lint, production Web export, a clean Android Release, the manifest and SecureStore dependencies.
